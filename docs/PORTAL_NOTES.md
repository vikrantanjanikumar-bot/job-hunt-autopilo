# Portal notes (stages 6 and 7)

What the common application systems do, learned the slow way. Add your own.

## All portals

- Upload the résumé first. Then open the experience and education pages: importers split one
  employer into several jobs (one per project), list customers as employers, and guess degrees.
  Delete what they invented and keep one accurate entry per real job.
- Phone fields often reject a "+" or spaces: type digits only and pick the country code.
- A salary box that takes numbers only and is optional: leave it empty rather than invent.
- If a field fails twice, read its limits (maximum length, allowed values, error text) before
  trying another way of clicking.
- Never set a field's value by script on React-style forms; type it or pick it.
- Read every page back before submit. "Filled" means checked, not typed.

## Workday

- Flow: résumé autofill, My Information, My Experience, questions, disclosures, review.
- Dropdowns are buttons: click, then pick the option by its exact text (state names may carry
  accents).
- Language rows can need several levels each (overall, speaking, writing).
- A text box may hold hidden imported text: select all before typing.
- Degree lists differ by employer; choose the nearest honest level and put the real name in
  the school or grade field.

## SuccessFactors

- The profile keeps old documents: replace both résumé and cover letter each time.
- Education needs level and field from the employer's own scale.

## Eightfold

- Uploading a résumé raises a data-privacy consent before anything else.
- Screening questions are per job and long; answer from the facts file only.

## Oracle Recruiting

- Email plus one-time code to start; ends with a typed-name e-signature. Both are the candidate's.

## Naukri and similar boards

- "Apply" uses the saved profile and résumé; keep the profile current.
- Profile key skills have a total character limit; when full, the add box silently ignores input.

## LinkedIn

- "Easy Apply" needs a résumé uploaded through the system file picker once.
- "Apply on company website" opens the employer's page in a new tab; use that for tailored documents.

## Things only the candidate does

Sign-ins, account creation, one-time codes, CAPTCHAs, e-signatures, and consents unless the
facts file says the assistant may tick them.
